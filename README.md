# IchorPad Macropad

This is the repo for the firmware and case files for the IchorPad.

### Flashing Firmware Instructions:

1. Once assembled plug in the RP2040 while holding the bootselect button, the device will show up as an external drive.
   
2. Download one of the .uf2 files and drag and drop it into the external drive.  
3. Now that you've flashed the firmware, either go to https://www.usevia.app/ or download the app here: https://github.com/the-via/releases/releases  
4. Now that you're in VIA, upload the corresponding via.json file from the folder that you downloaded your uf2 in the design tab.
